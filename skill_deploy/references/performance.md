# 完整业绩判断：五维评分卡与综合评级

评分卡回答「这家公司本期业绩本身怎么样」，预期对照回答「相对市场预期怎么样」。
两者**互相独立**：无机构覆盖的公司评分卡照常输出（这正是它存在的主要理由）；
有机构覆盖时，总评两面呈现（评级 + 达标情况），不允许只讲有利的一面。

## 数据底座

- `fetch_financial.py`：摘要多期序列（增速、季节系数、单季拆解）
- `fetch_statements.py`：三大报表明细（费用/有息负债/商誉/capex）+ 主营构成近两期（驱动拆解）
- `fetch_market.py`：市值（ROE-TTM 分母、估值联动）

## 核心算式（perf_math.py，报告内写明算式与数字）

- 单季值 = 本期累计 − 上期累计；单季同比的上年同季单季 = 上年累计差（如 Q2'25 = H1'25 − Q1'25）
- TTM 归母净利 = 上年年报 + 本期累计 − 上年同期累计
- ROE-TTM = TTM 归母净利 / 期末归母净资产
- 净现比 = 经营现金流净额 / 归母净利（累计口径）
- FCF = 经营现金流净额 − 购建长期资产支付的现金
- capex 强度 = 购建长期资产支付现金 / 经营现金流净额
- 四费费率 =（销售 + 管理 + 研发 + 财务费用）/ 营业总收入
- 有息负债 = 短期借款 + 长期借款 + 应付债券
- 非经常性占比 = 1 − 扣非净利润 / 归母净利润
- 增速剪刀差 = 归母净利同比 − 营收同比

## 五维评分卡（每维 tone ∈ good/warn/bad，判定必须引用表内可复算的数字）

### 1. 成长性 growth

默认阈值适用成长/制造类；稳态类（公用事业、消费必需等）可将阈值下调一半并在报告注明。

- **good**：营收与归母净利单季同比均 ≥ +10%，且剪刀差 ≥ 0（利润跑赢营收）
- **bad**：营收单季同比 < 0，或归母净利单季同比 < 0（扭亏为盈不算 bad，判 warn 并注明「扭亏」）
- **warn**：其余
- 必列附注：扣非口径增速；非经常性占比 > 30% 时标注「一次性推高」

### 2. 盈利能力 profitability

- **good**：毛利率 ≥ 近 8 期中位数且单季环比不降，且 ROE-TTM ≥ 10%
- **bad**：毛利率 < 近 8 期中位数且单季环比降幅 > 1pct，或 ROE-TTM < 5%
- **warn**：其余
- 必列附注：四费费率同比变动（费用率上升吞掉毛利改善必须明说）；杜邦定位 ROE 变动主因（净利率 / 周转 / 杠杆）

### 3. 盈利质量 quality

- **good**：净现比 ≥ 0.8，且非经常性占比 ≤ 15%，且未触发 metrics.md 质量预警
- **bad**：净现比 < 0.5，或非经常性占比 > 50%，或触发任一质量预警（应收/存货异常、现金流连续两期偏低）
- **warn**：其余
- 数据缺失子项（如金融业无存货、部分公司无应收账款行）不计入，判定基于可得子项并注明

### 4. 财务健康 health

- **good**：有息负债 ≤ 货币资金，且商誉/归母净资产 < 10%
- **bad**：商誉/归母净资产 ≥ 30%，或有息负债 > 货币资金 × 2，或资产负债率 ≥ 70%
  （金融/地产/重资产行业负债率天然高，按行业惯例调整并注明）
- **warn**：其余
- 必列附注：资产负债率、有息负债/货币资金、商誉占比三个数字；FCF 为负时注明 capex 强度

### 5. 业绩驱动与可持续性 drivers（AI 定性，但必须引用分部数据）

- 逐分部拆解：主营构成近两期对照（分部收入增速、占比变化、分部毛利率变化），指明增量来自哪个业务
- 驱动归类：需求扩张 / 份额提升 / 价格变动 / 成本变动 / 一次性损益
- **good**：驱动为需求或份额类，且分部毛利率同步改善（可外推）
- **bad**：增长主要由一次性损益或单一价格因素推动
- **warn**：价格/成本波动驱动；或 capex 强度 > 1（投资期利润被压制，注明在建工程/固定资产较年初变化）

## 综合评级（grade_from_tones，规则可复算）

计分 good=+1 / warn=0 / bad=−1，五维求和：

| sum | 评级 | 文案 |
|---|---|---|
| ≥ 3 | A | 业绩优秀 |
| 1 ~ 2 | B | 业绩良好 |
| −2 ~ 0 | C | 业绩承压 |
| ≤ −3 | D | 业绩恶化 |

覆盖规则：成长性与盈利质量同为 bad 时至多 C（增长失速叠加含金量差，不允许落到良好档）。

## 与预期对照的合成（summary 措辞规范）

- 总评第一句：综合评级 + 一句话理由；第二句：预期对照结论（达标/未达标家数）
- 两面并存示例：评级 B 但关键指标 miss →「业绩本身良好，但低于机构预期线」；
  评级 C 但超预期 →「超预期的多是降幅收窄，业绩本身仍在承压」
- summary tone：评级 A/B → good、C → warn、D → bad，与预期对照 tone 取**更差**者
- 报告 sections 顺序：评分卡（含综合评级）放第一模块，预期对照紧随其后
