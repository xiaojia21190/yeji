# 前景与催化：核心优势、订单前瞻、影响走势的因素

三类判断各管一段：评分卡看「过去一期业绩本身」（references/performance.md），
预期对照看「相对市场预期」（references/methodology.md），本模块看「**往前看什么**」
——公司的核心竞争力、需求的领先指标、业绩数字之外会影响股价走势的因素。

输出三张表 + 一段结论。每行都要有量化证据或可溯源出处，不接受形容词堆砌。

## 1. 核心优势（竞争格局）

| 优势类型 | 证据要求 | 数据来源 |
|---|---|---|
| 市占率/行业地位 | 排名或份额数字（全球/国内第几、份额 %） | WebSearch 研报/招股书/行业协会 |
| 技术/产品壁垒 | 高端产品占比、新品进展、认证/专利数量 | 研报、公司公告 |
| 客户结构 | 前五大客户占比、头部客户绑定（进入供应链名单） | 年报前五客户、WebSearch |
| 供应链地位 | 应付账款/营收（对上游占款能力）、预付款项/营收（备料强度） | statements.json（脚本） |
| 盈利相对优势 | 毛利率 vs 同行均值/最高值 | 同行模块对比表（已有） |

供应链占款是常用硬证据：应付账款/营收显著高于同行 = 产业链议价权强。

## 2. 订单与需求前瞻

**脚本可得**（statements.json 资产负债表，两期对照看方向）：

- **合同负债 + 预收款项**（perf_math.advance_liabilities/advance_ratio）：
  环比/同比抬升 = 在手订单前置信号；占营业总收入比 = 订单厚度
- **存货方向**：存货增速 > 营收增速但毛利率稳定或上行 = 主动备货（需求前置）；
  配合质量维排除滞销（metrics.md 预警）
- **应付/预付变化**：预付款项抬升 = 向上游锁料备产；应付账款抬升 = 占用供应商资金扩张

**WebSearch 溯源**（只收有原文出处的，记 URL）：

- 在手订单金额、重大合同、中标公告：搜「公司名 在手订单」「公司名 中标 亿元」
- 大客户资本开支计划（下游龙头 capex 指引对订单的传导）
- 产能扩张与投产时点：在建工程/固定资产变化 + 搜「公司名 扩产 投产」

**行业口径提醒**：to B 长账期行业（光模块、消费电子代工等）合同负债天然小
（如 300308 仅占营收 0.05%），订单前瞻以 WebSearch 的在手订单/大客户 capex 为主，
合同负债仅作辅助；to C 预收制行业（白酒、教育、SaaS）合同负债是核心前瞻指标。

## 3. 影响走势的因素（业绩数字之外）

checklist 逐项过；无相关因素的项写「未发现」并附检索词，**不硬凑**：

| 类别 | 检查项 | 检索词示例 |
|---|---|---|
| 股权供给 | 限售解禁时点与规模、大股东/董监高减持计划、回购/增持 | 「公司名 解禁」「公司名 减持」 |
| 筹码结构 | 股东户数趋势（集中/分散）、机构持仓变化 | 「公司名 股东户数」 |
| 资本运作 | 定增/可转债/并购重组/分拆上市 | 「公司名 定增」「公司名 并购」 |
| 风险事件 | 股权质押比例、诉讼/监管处罚、汇率与原材料价格敏感度 | 「公司名 质押」「公司名 诉讼」 |
| 行业景气 | 政策变化、行业周期位置（涨价/跌价）、技术路线切换风险 | 「行业名 2026 价格」「行业名 政策」 |
| 催化剂 | 新品发布、产能投产、大订单落地、业绩指引调整 | 「公司名 新品」「公司名 扩产」 |

输出格式：每因素一行——因素 / 方向（利好·利空·中性）/ 时效（短期一次性·持续）/ 依据出处。
方向只描述市场共识逻辑，不预测股价（与全 skill 一致：不构成投资建议）。

## 行业画像接入

走势因素与驱动拆解有行业专属变量时（资源股的金价铜价、银行的息差、白酒的批价等），
按 `references/industries/` 命中的画像特化：画像定义的**核心跟踪变量与行业检查项**
优先于本文件的通用 checklist（替代「行业景气」类，其余类别照常执行）；驱动拆解、
评分卡阈值、估值选型同样按画像条款覆盖。多品种公司按主营收入占比取前两类画像。
命中画像须在报告注明「本报告按 XX 画像特化」。

## 结论与呈现

- 三张表各配 conclusion 一句话：优势是否可持续、订单能见度（季度/年度级）、最大的 1~2 个走势变量
- section id 固定 `outlook`，模块顺序放在 scorecard 之后、expectation 之前（判定之后紧接前瞻）
- summary 中 outlook 的最重要发现（如订单能见度、临近解禁）占 1 句
- 溯源纪律同全 skill：WebSearch 只收有原文出处的数字并记 URL；两源冲突并列列出
