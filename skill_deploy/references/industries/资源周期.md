# 画像：资源周期（贵金属 / 工业金属 / 能源 / 化工资源型）

适用：利润主要由矿产品/能源/化工品「采掘量 × 商品价格」决定的公司。
判定特征：研报行业字段为有色/黄金/煤炭/石油/化工上游；主营构成按产品分类下
出现金/铜/锌/原油及冶炼产品。典型：紫金矿业（铜+金）、山东黄金、洛阳钼业、
江西铜业、中国海油。一个公司多品种（紫金=铜+金）按收入占比取前两类并列跟踪。

本报告按资源周期画像特化。核心逻辑：**商品价格是第一性变量，公司业绩 = 量 × 价 − 成本**。

## 1. 核心跟踪变量

| 变量 | 取数 | 用途 |
|---|---|---|
| 商品价格（按主营品种选主力合约，如金 AU0、铜 CU0、银 AG0、油 SC0） | `fetch_commodity.py AU0 CU0` → last / chg_ytd / chg_1y / **range_pos（一年价格分位）** | 走势因素表、周期位置、量价拆解的价 |
| 美元指数与实际利率（贵金属必备，铜次要） | WebSearch「实际利率 美元 金价」 | 金价的宏观锚，走势因素表必列 |
| 库存与加工费 TC/RC（冶炼占比高时） | WebSearch「铜 TC 加工费」「LME 库存」 | 冶炼利润的前瞻 |
| 汇率（海外收入占比高，如紫金境外 ~95% 营收） | 摘要模块已有毛利对照；WebSearch「人民币汇率」 | 换算与汇兑损益 |
| 公司产量与成本（矿产金/铜产量、克金成本、C1 成本） | 季报经营数据公告、WebSearch「公司名 产量 克金成本」 | 量价拆解的量与成本 |

外盘（COMEX/LME）与国内主力背离时并列列出（fetch 脚本只覆盖国内主力）。

## 2. 驱动拆解口径（替代通用驱动归类）

- **量价拆解**：营收变动 = 量变动（产量/销量吨位）+ 价变动（报告期商品均价同比）。
  产量取公司季报经营数据公告；均价用 fetch_commodity 历史窗口内报告期均值，
  或 WebSearch 溯源的机构测算
- **成本刚性 → 利润弹性非线性**：成本相对固定时价格涨幅会放大到利润端（经营杠杆），
  反之亦然；毛利率随商品价格同向大幅波动属正常经营特征，**不作为质量预警**
- **套保**：披露套保比例的公司，价格弹性按套保比例折扣，报告中注明

## 3. 评分卡调整（仅列与通用规则的差异）

- **成长性**：周期高位的价格贡献不计入「成长」——量增带来的增长才判 good；
  纯价格驱动的同比高增判 warn 并注明「价格驱动，随商品价格回落可逆」
  （与 performance.md 价格因素判 warn 一致，此处收紧为强制）
- **盈利能力**：毛利率环比随商品价格波动 ±3pct 内不触发标注；ROE-TTM 阈值改用
  「vs 自身上一轮周期均值」而非固定 10%/5%
- **盈利质量**：净现比阈值放宽到 ≥ 0.6（矿企税款/库存占用节奏与制造业不同）；
  存货为待售矿产品时不算滞销预警
- **财务健康**：出海矿企关注资源国地缘与币种错配，商誉条款照旧
- **周期位置**（必列附注）：主力合约 range_pos ≥ 0.85 注明「周期高位」、≤ 0.15 注明
  「周期低位」；高位时 summary 必须提示业绩对价格的敏感性

## 4. 估值选型

PE 在周期顶底失真（顶位低 PE ≠ 便宜）。按 metrics.md 周期股条款执行：

1. **周期中枢盈利法**（默认）：用跨周期归母中枢（近 5~7 年均值或机构中枢盈利）× 8~12x
2. **储量/资源市值法**（矿企可选）：市值 / 权益资源量（吨金属市值），与同行对照
3. **分部估值**：多品种公司（紫金=铜+金）分品种给区间再加总

「合理 PE 估算」小节的口径净利一律用周期中枢盈利，禁用单年峰值。

## 5. 走势因素特化（outlook 模块检查项，替代通用清单的「行业景气」类）

| 检查项 | 说明 |
|---|---|
| 商品价格趋势与分位 | fetch_commodity 数字直接引用；range_pos 判周期位置 |
| 美联储路径与实际利率（金/银） | 降息/加息预期对金价的传导 |
| 美元指数（跨境定价） | 强美元压制金属价格 |
| 全球库存周期与加工费（铜/冶炼） | TC 下行 = 矿端紧张，利好矿企利空冶炼 |
| 新矿投产 / 并购 / 增储 | 量增逻辑，公司特有催化 |
| 资源国政治与地缘（海外占比高时） | 税制、国有化、出口政策、安全事件 |
| 环保/安全督查（国内矿） | 停产整顿 → 量减价涨 |

通用清单（股权供给/筹码/资本运作等）照常执行，两类合并输出。
