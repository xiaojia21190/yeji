# 行业画像机制（references/industries/）

行业画像是可插拔的方法论扩展：命中画像的行业，其「核心跟踪变量、驱动拆解口径、
评分卡阈值调整、估值选型、走势因素清单」由画像文件特化，未命中走通用流程。

## 机制

1. **判定**（SKILL.md 第 0 步）：用研报列表行业字段 + 主营构成判定公司行业属性
2. **加载**：命中下方清单 → 读取对应画像，报告中注明「本报告按 XX 画像特化」；
   一个公司跨多类（如紫金=铜+金）按主营收入占比取前两类并列加载
3. **优先级**：画像条款覆盖通用模板的对应项；画像未覆盖处仍走 references/ 通用规则
4. **港股**：画像同样适用（数据改财报原文 + WebSearch）

## 现有画像

| 文件 | 适用行业 | 核心特化 |
|---|---|---|
| `资源周期.md` | 贵金属/工业金属/能源/化工资源型（紫金矿业、山东黄金、洛钼、江铜、中国海油等） | 商品价格联动、量价拆解、周期位置、PE 失效估值 |

## 新增画像的必备段落

新建 `{行业名}.md` 后在上方清单登记。画像文件必须包含以下段落（模板见资源周期.md）：

1. **适用与判定**：什么公司命中（行业字段关键词 + 主营构成特征）
2. **核心跟踪变量**：该行业股价与业绩的第一性变量，及脚本/WebSearch 取数方式
3. **驱动拆解口径**：营收/利润变量的行业专属拆解公式（替代通用 checklist 的对应项）
4. **评分卡调整**：五维中哪些阈值/口径需要行业化调整（必须写明调整理由）
5. **估值选型**：该行业用什么估值方法（或声明 PE 失效的替代法）
6. **走势因素特化**：outlook 模块影响走势因素表的行业专属检查项

原则：画像只写「这个行业和别的行业不一样的地方」，不复述通用流程。
