## 1. 目标与边界

### 目标

做一个通用财报分析 skill：输入 A 股公司代码，产出一份图中风格的 **HTML 对照分析报告**，覆盖四个模块：

1. **业绩 vs 机构预期对照**（核心，复刻参考报告的方法论）
2. **财务趋势与质量分析**
3. **同行横向对比**
4. **估值水平评估**

### 参考报告方法论（复刻对象）

以「中际旭创 2026 中报 vs 机构预期」报告为蓝本：

- **反推对照**：投行只给全年预测 → 用季节系数（净利 39.2% / 营收 43.4%）摊到 H1 → 减 Q1 得 Q2 反推值 → 与实际披露值逐项对照
- **四项核心指标逐项判定**：Q2 归母净利 / 扣非净利 / 营收 / 毛利率，各给「符合 / 不符合预期」结论
- **差额拆解**：归母 − 扣非的差额拆到非经常性损益明细
- **严格溯源**：每个机构数字标注出处，剔除无原文依据的机构，「只列事实与数字，不构成投资建议」

### 边界（首版不做）

- 港股 / 美股 / 未上市主体（仅 A 股，含北交所）
- 财务造假法务式审计、DCF 深度估值建模
- tdx2db 本地行情数据库（方案 B，留作后续升级）
- 自动定时跑批（skill 按需触发）

**分工原则**：脚本只做「稳定取数」（AI 不擅长、易错的重复 HTTP 调用与字段清洗）；分析判断、口径选择、结论措辞、溯源标注全部由 AI 在会话内完成——这是参考报告的核心价值所在。

## 4. 模块设计

### 4.1 业绩 vs 机构预期对照（核心模块）

**输入**：最新一期财报数据 + 机构预测集合。

**流程**：

1. 确定报告期（如 2026 中报）与对照指标（归母净利、扣非净利、营收、毛利率）
2. 收集机构预测：
   - 国内卖方：`fetch_forecast.py`（东财研报列表，含 EPS/净利预测、评级、日期、PDF 链接）
   - 外资行（高盛/大摩/野村/瑞银等）：WebSearch 搜新闻稿，只收录有原文出处的
   - 无原文依据的一律剔除并在报告中注明
3. 反推计算（AI 完成，算式写进报告）：
   - `Q2 = 全年预测 × 季节系数 − Q1 实际`
   - 季节系数默认用「历史同期占比」（如净利 H1/全年 = 39.2%），有机构原文单季值时用原文校准
   - 系数无法确定时，改用区间对照而非点值，并说明局限
4. 逐机构、逐指标判定「达标 / 未达标」，差额精确列示
5. 归母 − 扣非差额拆解到非经常性损益明细

**输出**：指标卡片（6 张）+ 每指标一张机构对照表 + 结论色块（绿=符合 / 粉=不符合）+ 反推方法附录与数据来源明细。

### 4.2 财务趋势与质量分析

- 营收 / 归母净利 / 扣非净利 / 毛利率：近 8~12 期序列 + 单季环比同比
- 盈利质量：经营现金流 / 归母净利比值、应收与存货增速 vs 营收增速
- 简版杜邦：净利率 × 总资产周转率 × 权益乘数，拆解 ROE 变动来源
- 异常信号自动标记：现金流持续为负、应收激增、毛利率骤变等

### 4.3 同行横向对比

- 同行集合：默认取东财研报里的同行业成分（申万/东财行业分类），WebSearch 复核「市场公认可比公司」，AI 最终确认
- 对比指标：营收增速、归母净利增速、毛利率、ROE、PE-TTM
- 表格 + 简短点评，不展开个股深度分析

### 4.4 估值水平评估

- 现价、总市值（`fetch_market.py`）
- PE-TTM、PE-2026E / 2027E（用研报盈利预测计算，逐机构列示）
- PEG（如增速数据可得）
- 结论限定为「事实陈述」：对应哪年预测多少倍 PE，不给买卖建议

## 5. 数据源策略（分层与降级）

| 层级 | 数据 | 主源 | 降级链 |
|---|---|---|---|
| 1 | 财报实际值（多期） | akshare `stock_financial_abstract`（新浪） | 同花顺摘要 → 新浪三大报表 |
| 2 | 机构预测（国内卖方） | akshare `stock_research_report_em`（东财） | WebSearch 搜研报新闻稿 |
| 3 | 机构预测（外资行） | WebSearch 新闻稿 | 无则标注「未获取」并剔除 |
| 4 | 一致预期 | akshare 盈利预测接口 | 接口偶发 None → 重试 1 次 → 改用研报列表自行汇总 |
| 5 | 行情 / 市值 | akshare 实时行情 | tdx（Go，可选，未部署则跳过） |

**数据校验规则**：反推基数（全年预测）与被对照值（实际披露）必须单位一致（亿元）；EPS 口径预测 × 总股本换算净利时股本取最新；任一关键数字两个来源冲突时，报告中并列列出并标注差异，不擅自取舍。

## 6. HTML 报告规范

- 单文件 HTML，内联 CSS/JS，无外部依赖，可直接转发
- 结构（自上而下）：
  1. 头部：代码 · 报告期 · 主标题
  2. 核心指标卡片行（6 张：Q2 归母 / Q2 扣非 / Q2 营收 / Q2 毛利率 / H1 归母 / H1 经营现金流）
  3. 四模块依次展开，每指标：机构对照表 + 结论色块
  4. 附录：反推方法说明 + 数据来源明细表 + 免责声明
- 视觉：图中同款——白底、指标卡片、绿色=符合 / 粉色=不符合 色块、等宽数字
- 文件命名：`{代码}_{公司名}_{报告期}_财报分析_{YYYYMMDD}.html`，输出到当前工作目录

## 8. 错误处理

- akshare 接口失败：按降级链换源；全链失败则停止并明确告知，不用编造数据
- 非财报披露期（如年报未出）：提示可用最新一期，或降级为趋势+估值模块
- 机构预测全缺失（小盘股常见）：预期对照模块输出「无可靠预测，跳过」并说明，其余模块照常
- WebSearch 无结果：标注「未能溯源」，该机构不纳入对照
