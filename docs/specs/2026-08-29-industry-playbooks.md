# 行业画像机制 + 商品价格取数设计

- 日期：2026-08-29
- 状态：已实现（AU0/CU0 实测 + 全量测试通过）
- 前置：前景与催化模块（2026-08-29）

## 1. 问题

通用模板对资源股失真：紫金矿业的股价与业绩第一性变量是金价铜价，通用 checklist
的「行业景气」一项装不下这类联动——量价拆解、克金成本、周期位置、PE 失效、
资源国地缘等都是行业专属判断。用户问「紫金跟黄金的关系怎么特意化」。

## 2. 方案：可插拔行业画像

`references/industries/` 目录按行业放画像文件，命中即加载并覆盖通用模板对应项：

- 判定：研报行业字段 + 主营构成；多品种公司按主营占比取前两类（紫金=铜+金）
- 画像必备段落：适用与判定 / 核心跟踪变量 / 驱动拆解口径 / 评分卡调整 / 估值选型 / 走势因素特化
- 原则：画像只写「与别的行业不一样的地方」，机制文档见 `industries/README.md`

首份画像 `资源周期.md`（金铜/能源/化工资源型）要点：

- 核心变量：商品主力合约价格、美元与实际利率（贵金属）、TC/RC 与库存（铜）、汇率、产量与克金成本
- 评分卡调整：纯价格驱动的增长判 warn（可逆）；毛利率随价波动不触发质量预警；
  净现比阈值放宽；range_pos ≥ 0.85 / ≤ 0.15 标注周期位置
- 估值：PE 失效 → 周期中枢盈利法 / 储量市值法 / 分品种加总
- 走势因素：商品价格+宏观锚+公司特有（新矿投产/并购/地缘），通用清单照常合并

## 3. 数据支撑：fetch_commodity.py

- 新浪期货主力连续（`futures_main_sina`，秒级）：`fetch_commodity.py AU0 CU0`
- 输出 last / chg_1m / chg_3m / chg_ytd / chg_1y / **range_pos（一年价格分位，周期位置信号）**
- 实测：沪金 999.28 元/克（1y +27.6%，分位 0.48）；沪铜 108900 元/吨（1y +38.0%，分位 0.98 顶部）
- 外盘 COMEX/LME 不在脚本范围，背离时 WebSearch 补充并列
